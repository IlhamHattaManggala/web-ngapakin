# web-ngapakin

Proyek aplikasi web Larapak sing digawe nganggo struktur dialek Ngapak.

## Cara Menjalankan

### Opsi 1: Menggunakan CLI Lokal
1. Masuk ke direktori proyek:
   ```bash
   cd web-ngapakin
   ```
2. Jalankan server lokal:
   ```bash
   ngapakin serve 8000
   ```
3. Buka peramban di `http://localhost:8000`.

### Opsi 2: Menggunakan Docker (Tanpa Install Python)
1. Jalankan container:
   ```bash
   docker compose up -d
   ```
2. Buka peramban di `http://localhost:8000`.
